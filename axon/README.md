# Axon

Клиентский слой Synapth — «аксон», по которому сигнал уходит из Cortex к
пользователю и к агентам. Изоморфный код: работает в браузере, в Node и
внутри агента.

| Модуль | Роль |
|---|---|
| `client.ts` | типизированный клиент REST API `/api/v1` (веб-режим и агентный режим) |
| `install.ts` | генерация конфигов установки для Cursor / Claude Desktop / Claude Code |
| `hooks.ts` | React-хуки: установка, выполнение платного вызова |
