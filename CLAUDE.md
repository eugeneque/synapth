# Synapth — заметки для агента

- Отвечать по-русски; код и комментарии в коде — по-английски.
- Серверные модули только в `cortex/`, клиентские — в `axon/`; `lib/` — изоморфные утилиты. Route handlers в `app/api` не содержат бизнес-логики.
- Деньги — целые микродоллары (`types/economy.ts`), никакого float в леджере.
- `Verified` никогда не присваивается сканером — только через `reviewed: true`.
- БД: `DATABASE_URL` или `NETLIFY_DATABASE_URL` (Neon через Netlify DB) — резолвится в `cortex/db.ts` (`databaseUrl`). Схема на Neon синхронизируется `scripts/db-sync.mjs` (в сборке Netlify и `npm run db:sync`): разовые SQL-миграции данных + `prisma db push` без `--accept-data-loss`. Деструктивное изменение схемы → оформляй SQL-шагом в `PRE_PUSH_SQL`, а не флагом.
- Без `DATABASE_URL` всё работает на in-memory сторе (`cortex/repository.ts`, `cortex/billing.ts`); тесты (`npm test`) рассчитаны на этот режим.
- Проверка: `npm run typecheck && npm test && npm run build`.
- Каталог живёт в `data/catalog.json` (gitignored), обход — `npm run crawl`, бейджи — `npm run rescan`. Тесты пишут в `.test-catalog.json`, реальный каталог не трогают.
- Синглтоны в `globalThis` версионируются ключом (`__synapthRepo_v3`): при смене интерфейса репозитория поднимай версию, иначе HMR оставит старый экземпляр.
- Токен GitHub для краулера/импорта: `GITHUB_TOKEN` или `gh auth token` (`cortex/github-token.ts`); в `.env` его не записывать.
- Локализация: все строки UI — через `lib/i18n` (ключи в `messages/en.ts`, остальные локали типизированы по нему). Сервер — `getI18n()` из `cortex/locale.ts`, клиент — `useI18n()` из `axon/i18n.tsx`. Локаль — cookie `synapth_locale`, без префикса в URL. Инлайн-разметка в строках: `**strong**`, `*em*`, `` `code` `` → `rich()`.
- Маршруты: страницы сайта лежат в `app/(site)/` (общий хедер/футер в `app/(site)/layout.tsx`), auth-gate — в `app/(auth)/` со своим минимальным баром; корневой `app/layout.tsx` даёт только `<html>`, шрифты, `PixelField` и `I18nProvider`. `app/not-found.tsx` — глобальный 404 (оборачивает `(site)/not-found.tsx` в хедер/футер).
- Консоль: `app/(site)/dashboard/layout.tsx` рисует рейл `ConsoleNav`; настройки аккаунта — `/dashboard/settings` (`cortex/account.ts`, server action в `settings/actions.ts`, после сохранения `updateSession()` обновляет JWT). Предпочтение клиента установки зеркалится в cookie `synapth_target`, его читает `defaultTarget()` из `axon/install.ts`.
- Профили: публичная страница пользователя — `/u/[handle]`; `/authors/[owner]` остаётся для GitHub-владельцев из краулера и редиректит на `/u/…`, если хендл принадлежит зарегистрированному аккаунту. Аватар (`User.image`) и обложка (`coverImage`) хранятся как `data:image/*;base64` (клиент сжимает в `axon/image.ts`, лимиты — `types/profile.ts`); в JWT картинку не класть — хедер берёт её из `getProfile()`. Список профессий (`occupation`) — `OCCUPATIONS` в `types/profile.ts`, подписи — ключи `occupation.<id>`.
- Схема Prisma: у `User` добавлены `bio`, `organization`, `website`, `location`, `occupation`, `coverImage`, `defaultTarget` — при реальной БД нужен `npm run db:push`.
- `memoryUsers` (in-memory юзеры) тоже живут в `globalThis` (`__synapthUsers_v1`) — по той же причине, что и репозиторий.
- Соцслой (`cortex/social.ts`): «лайк» называется **импульс** (`Impulse`, один на пару from→to, тумблер), посты (`Post`), комментарии (`Comment`, полиморфные: `targetKind` post|skill — навыки/MCP/инструменты это один `Skill`), отслеживание (`SkillWatch`). Мутации идут через server actions в `app/(site)/social-actions.ts`; после событий вызывается `evaluateBadges()`.
- Уведомления (`cortex/notifications.ts`): чистый inbox, виды в `NOTIFICATION_KINDS` (`types/social.ts`), у каждого — канал для табов (`NOTIFICATION_CHANNEL`). Репозиторий при смене версии навыка зовёт `notifySkillUpdated()` (watchers, кроме автора). Клиент: `axon/notifications.tsx` поллит `GET /api/v1/notifications?after=` каждые 20 с, новые строки → тост (`axon/toast.tsx`, `useToast()`) + чайм `public/sounds/notification.mp3` (mute в localStorage `synapth_notif_muted`). Шторка — `components/notification-center.tsx`, страница — `/dashboard/notifications`. Тексты карточек/тостов — `axon/notification-text.ts` (у actor-фраз `{name}` всегда первым, `verb` = фраза без имени).
- Бейджи (`types/badges.ts` + `cortex/badges.ts`): каталог в коде (`BADGES`, критерии `BADGE_CRITERIA`), в сторе только выдачи (`UserBadge`). `evaluateBadges()` идемпотентен; ручные (`award: "manual"`) — только `grantBadge()` админом. Подписи — ключи `badge.<id>.title|body`.
- Новые Prisma-модели: `Impulse`, `Post`, `Comment`, `SkillWatch`, `Notification`, `UserBadge` — `npm run db:push` при реальной БД. In-memory демо-строки соцслоя — в конце `cortex/seed.ts`.
- Регистрация — `cortex/registration.ts`: пароль (`registerWithPassword`, route `/api/auth/register` — тонкий) и первый OAuth-вход (`createOAuthUser`, подключён как `adapter.createUser` в `cortex/auth.ts`). Оба создают юзера + кошелёк + welcome-кредит одной вставкой. Хендлы — `handleSchema`/`isReservedHandle` (служебные слова и префикс `gh-` краулера). Ошибки с `code` → `auth.err.<code>` на клиенте. На serverless без БД регистрация отдаёт 503 (иначе аккаунт жил бы в памяти одной лямбды).
- Роли: `user` < `moderator` < `admin`; права — `PERMISSIONS`/`can()` в `types/auth.ts` (admin = все, включая будущие). Проверки — `cortex/roles.ts` (`requirePermission`, `hasPermission`) по **роли из стора**, не из JWT; для сессии — `requireSessionPermission`, для API-ключей — `requireCallerPermission`. Верификация каталога — `cortex/moderation.ts` (`setVerification`: сканер с `reviewed: true`, аудит в `SecurityScan.reviewedBy`). Смена ролей — только админ, не себе, не последнему админу; первый админ — `npm run role -- <email|handle> admin`.
- Безопасность (не откатывать):
  - Любой пользовательский URL — только через `lib/url-safety.ts` (`httpUrlSchema` в zod-схемах, `safeExternalHref`/`safeImageSrc` при рендере, `safeCallbackPath` для редиректов). Голый `z.string().url()` пропускает `javascript:` и `data:`.
  - Серверный `fetch()` по адресу из пользовательских данных — только `safeFetch()`/`assertPublicUrl()` из `cortex/ssrf.ts` (DNS-резолв, приватные диапазоны, редиректы, лимит тела). Локальная отладка — `SYNAPTH_ALLOW_PRIVATE_FETCH=1` (в проде игнорируется).
  - Каждый мутирующий и дорогой эндпоинт + server action проходит через `cortex/rate-limit.ts` (`enforceRequestLimit` / `enforceRateLimit`); бюджеты — в `RATE_LIMITS`.
  - Краулер (`/api/v1/crawl`, панель на дашборде) — только право `crawler.run` (admin, `requireCallerPermission`); в in-memory демо админ — `usr_demo`.
  - `upsertMany()` не перезаписывает навык с чужим `authorId` (считает в `skipped`) — иначе импорт похожего репозитория угоняет чужой слаг.
  - Заголовки безопасности и CSP — в `next.config.ts`; CORS `*` только для публичного чтения каталога (`PUBLIC_API_PATHS`), приватные `/api/v1/*` — same-origin.
  - Ответы апстрима в `/skills/:id/execute` наружу не проксируются (только свои сообщения) — тело апстрима это канал SSRF-утечки.
